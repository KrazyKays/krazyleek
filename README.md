# KrazyLeek

Atelier pour concevoir et optimiser des IA Leek Wars (LeekScript v4) avec Claude Code.

- Instructions pour Claude : [`CLAUDE.md`](CLAUDE.md)
- Profil du joueur à remplir : [`docs/context/profile.md`](docs/context/profile.md)
- Code des IA : [`ai/`](ai/)
- Docs LeekScript : [`docs/leekscript/`](docs/leekscript/)

## Commandes Claude
- `/leek-write <besoin>` : écrire ou modifier un module d'IA en respectant les conventions.
- `/leek-review [fichier]` : relire une IA (bugs, opérations, cas limites).
